# CombatChime

FF14 の戦闘ログから、攻撃1発ごとの判定音と「もうすぐ起きること」の予告音を鳴らす
ACT + OverlayPlugin 用のカスタムオーバーレイです。

> **重要**: 本ツールは**発音のみ**を行います。入力の自動化・ボット機能は一切なく、
> ゲームメモリの読み取りも行いません(ACT のログに現れる情報のみを使用します)。
> 外部ツールの利用は自己責任でお願いします。

## 使い方

OverlayPlugin(ngld版)のカスタムオーバーレイとして次のURLを登録します:

```
https://teck-sierra.github.io/combat-chime/
```

画面には右上の歯車(ホバーで浮き上がる)だけが出ます(通常時は完全に透明)。
設定はすべて歯車から。`?debug` を付けると接続状態と直近の判定が左上に出ます。

## 鳴るもの

ログから**自分の攻撃1発ごと**に判定して鳴らす「判定SE」5種と、
**もうすぐ起きること**を知らせる「予告SE」3種があります。

| 種類 | 何で鳴るか | 既定 |
|---|---|---|
| 方向指定 成功 / 失敗 | 背面・側面を取れたか(メレー6ジョブ) | 成功のみON |
| クリティカル / DH / クリDH | そのヒットの判定 | クリDHのみON(ジョブごとの威力TOP3の技だけ) |
| DoT切れ予告 | 自分がかけたデバフが切れる n 秒前 | **ON** |
| 自己バフ切れ予告 | 自分のバフが切れる n 秒前 | OFF |
| リキャスト明け予告 | 30秒以上のリキャストが明ける n 秒前 | OFF |

- 予告のタイミング(n)は既定5秒。設定画面で 3 / 5 / 8 秒から選べます
- 鳴らす対象は**ジョブごと・スキル(ステータス)ごと**にON/OFFできます。全21戦闘ジョブ対応
- 音はすべて WebAudio によるリアルタイム合成で、外部アセットはありません
